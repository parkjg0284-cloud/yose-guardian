## 🎮 게임 소개

요새를 지키는 **1인칭 슈터 + 타워 디펜스** 하이브리드 게임입니다.
웨이브를 막아내며 포탑을 짓고, 자원을 캐고, 마법을 연성해 요새를 지키세요.
친구와 **최대 4인 협동**도 가능합니다.

### 주요 특징

| 기능 | 설명 |
| --- | --- |
| **싱글 플레이** | 시드 기반 절차 생성 세계, 난이도 4단계 |
| **멀티플레이** | 초대코드 / 열린 방, 최대 4인 협동 |
| **친구** | 친구 코드로 추가 → 친구 서버(방)로 바로 들어가기 (`U`) |
| **전직 시스템** | 7개 계열 — 쌍권총 건마스터 포함, 메인코어 근처에서 E |
| **마법연성 · 아르카나** | 재료 조합으로 스킬 획득 |
| **요새 방어** | 웨이브 · 보스 · 포탑 20종 · 무기 75종 |
| **몬스터 외형** | 종류별 괴물 실루엣 — 뿔 · 턱 · 이빨 · 발톱 · 망토 · 날개 |
| **무기 스킬** | 무기를 들면 HUD 에 스킬 키(`R`)와 이름 · 쿨다운 표시 |
| **조준선 설정** | 설정에서 모양 6종 · 색 6종 · 크기 70~180% — 즉시 반영되고 브라우저에 저장됩니다 |
| **세이브 불러오기** | 메인 화면 [불러오기]로 최근 싱글 세이브를 바로 복원 (슬롯 목록은 설정에서) |
| **업적 · 도감 · 시드 갤러리** | 수집 요소 |

> 📚 **무기 75종 전체 목록** — 티어(T1~T7) · 유물 · 비밀(T8) · 원소 · 피해 · 쿨다운 · 궁극기: [docs/WEAPONS.md](docs/WEAPONS.md)

## 📥 다운로드

### 🎮 게임 다운로드 — 런처 exe (권장)

1. **[Releases](../../releases/latest)** 에서 **`YoseGuardian-Launcher.exe`** 내려받기 (약 667KB)
2. **더블클릭** — 창이 뜨면 **[게임 다운로드 & 설치]** 한 번
3. 최신 게임을 내려받아 `%LOCALAPPDATA%\YoseGuardian\app` 에 설치하고 **바로 시작**합니다

버튼은 설치 상태에 따라 바뀝니다.

| 상태 | 버튼 |
| --- | --- |
| 설치 전 | **게임 다운로드 & 설치** |
| 새 버전이 있을 때 | **업데이트 (v1.5.0 → v1.6.0)** |
| 이미 최신 | 버튼이 사라지고 **[게임 시작]** 만 남음 |

- 인터넷이 없으면 파일 안에 든 게임으로 설치됩니다.
- 설치 폴더를 지우면 **[게임 다운로드 & 설치]** 버튼이 다시 나타납니다.
- **[설치 파일 선택]** 으로 내려받아 둔 `game.zip` 을 직접 골라 설치할 수도 있습니다 (이전 판·오프라인 설치).
- 설치가 끝나면 바탕화면의 **요세의 수호자** 바로가기로 언제든 시작할 수 있습니다.

### 다른 방법

| 파일 | 설명 |
| --- | --- |
| `YoseGuardian-Setup.exe` | 설치 프로그램 (게임 내장, 인터넷 없이 설치) |
| `YoseGuardian-Downloader.exe` | 다운로더 앱 — 같은 설치 흐름을 다운로더 이름으로 |
| `YoseGuardian-launcher.zip` | 런처 압축본 (풀어서 `설치실행.cmd`) |
| `game.zip` | 게임 본체 (서버·수동 설치용) |

### 방법 — 직접 실행 (개발자)

```bash
git clone https://github.com/parkjg0284-cloud/yose-guardian.git
cd REPO
npm install && npm run build && npm start
```
→ http://localhost:3001

## 👥 친구

**`U`** 키로 친구창을 엽니다.

1. 친구창 위쪽에 **내 친구 코드**가 있습니다 (예: `ABCD-EFGH`) — [코드 복사] 로 복사해 친구에게 알려 주세요.
2. **[＋ 친구 추가]** → 열리는 입력창에 **친구 코드**를 넣고 [추가] 를 누릅니다.
3. 친구가 같은 서버(같은 PC·LAN)에 접속해 있으면 **접속 중** 으로 바뀌고 방 코드가 표시됩니다.
4. **[들어가기]** 를 누르면 친구의 서버(`http://주소/?room=방코드`)로 이동해 그 방에 참가합니다.
   - 주소를 모르면 안내 창에서 친구가 알려 준 `IP:포트`(예: `192.168.0.12:3001`)를 한 번만 입력하면 저장됩니다.
5. 친구를 지우려면 카드의 **[삭제]** 를 누릅니다.

> 친구 코드는 이 PC 에 저장됩니다. 서버는 접속 중인 플레이어의 코드·방 코드만 메모리에 두고 30분 동안 갱신이 없으면 오프라인으로 봅니다.

## 👹 몬스터

몬스터는 종류마다 다른 **괴물 실루엣**으로 만들어집니다.

| 부위 | 설명 |
| --- | --- |
| 몸통 · 머리 | 울퉁불퉁한 저폴리 덩어리, 자세에 따라 높낮이가 다르다 |
| 턱 · 이빨 | 벌어진 아가리와 위·아래 이빨, 오크는 엄니 |
| 뿔 · 등가시 | 머리 뿔과 척추를 따라 뒤로 뻗은 가시(보스는 더 많고 크다) |
| 팔 · 발톱 | 어깨에서 늘어진 팔과 세 갈래 발톱 — 공격 예고 때 휘두른다 |
| 눈 | 발광하는 눈(거미는 6개) — 상태이상·예고에 따라 색이 변한다 |
| 망토 | 망령 · 그림자는 반투명 망토를 두르고 떠다닌다 |
| 날개 | 박쥐 · 드레이크는 막 날개, 거미는 8개 다리 |

> 성능을 위해 부위는 한 지오메트리로 합쳐(정점 색) 드로우콜을 늘리지 않습니다 — 개체당 보이는 메시는 몸통·팔·눈·코어 4개입니다.

## ⚙️ 설정

`.env` 파일을 만들고 값을 채우세요 (`.env.example` 참고):

```ini
PORT=3001
NODE_ENV=production
ADMIN_USERNAME=admin
ADMIN_PASSWORD=여기에_강력한_비밀번호
ADMIN_NICKNAME=관리자
AUTH_SECRET=여기에_무작위_문자열
```

> ⚠️ `AUTH_SECRET` 은 **반드시** 바꾸세요. 이 값으로 로그인 토큰을 서명합니다.
> 무작위 값 만들기: `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`

### 관리자 계정

서버를 켜면 `.env` 의 값으로 **자동 생성/갱신**됩니다.
관리자만 `` ` `` 콘솔에서 명령어를 쓸 수 있습니다 (`/돈`, `/무기`, `/웨이브` 등).

- `.env` 에 `ADMIN_PASSWORD` 가 있으면 그 값이 항상 적용됩니다(서버 재시작 포함).
- 없으면 `server/data/admin-password.txt` 에 **한 번만 생성해 보관**하고, 다음 시작부터는 그 값을 씁니다.
  예전처럼 매 시작마다 무작위로 바뀌어 로그인할 수 없는 일은 없습니다.
- 비밀번호를 잊었다면 위 파일을 확인하거나 `.env` 의 `ADMIN_PASSWORD` 를 바꾼 뒤 서버를 다시 시작하세요.
- `/api/net` 의 공유 주소는 **실제 `PORT` 환경변수**를 사용합니다. 테스트(`node tools/e2e-net.mjs`)도
  `E2E_BASE` 의 포트를 읽으므로 3001 이 아닌 포트에서도 그대로 검증됩니다.
