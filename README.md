## 🎮 게임 소개

요새를 지키는 **1인칭 슈터 + 타워 디펜스** 하이브리드 게임입니다.
웨이브를 막아내며 포탑을 짓고, 자원을 캐고, 마법을 연성해 요새를 지키세요.
친구와 **최대 4인 협동**도 가능합니다.

### 주요 특징

| 기능 | 설명 |
| --- | --- |
| **싱글 플레이** | 시드 기반 절차 생성 세계, 난이도 4단계 |
| **멀티플레이** | 초대코드 / 열린 방, 최대 4인 협동 |
| **친구** | 친구 코드로 추가 → 친구 서버(방)로 바로 들어가기 (`U`) |
| **전직 시스템** | 8개 계열 — 요정 · 쌍권총 건마스터 포함, 메인코어 근처에서 E · 전직하면 그 직업의 1티어 무기를 지급 |
| **마법연성 · 아르카나** | 재료 조합으로 스킬 획득 |
| **요새 방어** | 웨이브 · 보스 · 포탑 20종 · 무기 82종 · 건물 최대 50개(시설 40개) · 티어마다 포탑 피해 +47% |
| **몬스터 외형** | 종류별 괴물 실루엣 — 뿔 · 턱 · 이빨 · 발톱 · 망토 · 날개 |
| **무기 스킬** | 무기를 들면 HUD 에 스킬 키(`R`)와 이름 · 쿨다운 표시 |
| **조준선 설정** | 설정에서 모양 6종 · 색 6종 · 크기 70~180% — 즉시 반영되고 브라우저에 저장됩니다 |
| **철거 모드** | `Z` — 조준한 포탑·시설을 철거하고 투자 재료의 25%를 돌려받습니다 (멀티는 내 건물만) |
| **자원 리스폰** | 나무와 광물이 **6초** 뒤 다시 자랍니다 — 채굴탑은 주변 광물이 없어도 맨땅을 시추합니다 |
| **시드 선택 불러오기** | 싱글 시드 줄의 [📂 불러오기]로 저장한 게임을 바로 이어서 합니다 (슬롯 목록은 설정에서) |
| **업적 · 도감 · 시드 갤러리** | 수집 요소 |

> 📚 **무기 82종 전체 목록** — 티어(T1~T7) · 유물 · 비밀(T8) · 원소 · 피해 · 쿨다운 · 궁극기: [docs/WEAPONS.md](docs/WEAPONS.md)

## 📥 다운로드

### 🎮 게임 다운로드 — 런처 exe (권장)

1. **[Releases](../../releases/latest)** 에서 **`YoseGuardian-Launcher.exe`** 내려받기 (약 671KB)
2. **더블클릭** — 창이 뜨면 **[게임 다운로드 & 설치]** 한 번
3. 최신 게임을 내려받아 `%LOCALAPPDATA%\YoseGuardian\app` 에 설치하고 **바로 시작**합니다

버튼은 설치 상태에 따라 바뀝니다.

| 상태 | 버튼 |
| --- | --- |
| 설치 전 | **게임 다운로드 & 설치** |
| 새 버전이 있을 때 | **업데이트 (v1.5.0 → v1.6.0)** |
| 이미 최신 | 버튼이 사라지고 **[게임 시작]** 만 남음 |

- 인터넷이 없으면 파일 안에 든 게임으로 설치됩니다.
- 설치 폴더를 지우면 **[게임 다운로드 & 설치]** 버튼이 다시 나타납니다.
- **[설치 파일 선택]** 으로 내려받아 둔 `game.zip` 을 직접 골라 설치할 수도 있습니다 (이전 판·오프라인 설치).
- 설치가 끝나면 바탕화면의 **요세의 수호자** 바로가기로 언제든 시작할 수 있습니다.

### 다른 방법

| 파일 | 설명 |
| --- | --- |
| `YoseGuardian-Setup.exe` | 설치 프로그램 (게임 내장, 인터넷 없이 설치) |
| `YoseGuardian-Downloader.exe` | 다운로더 앱 — 같은 설치 흐름을 다운로더 이름으로 |
| `YoseGuardian-launcher.zip` | 런처 압축본 (풀어서 `설치실행.cmd`) |
| `game.zip` | 게임 본체 (서버·수동 설치용) |

### 방법 — 직접 실행 (개발자)

```bash
git clone https://github.com/parkjg0284-cloud/yose-guardian.git
cd REPO
npm install && npm run build && npm start
```
→ http://localhost:3001 (기본 포트 — `.env` 의 `PORT` 로 바꿀 수 있습니다)

### 메인화면 · 런처 (v1.18.0)

- 메인화면(싱글·멀티 카드)의 **[불러오기] 버튼을 모두 제거**했습니다. 세이브를 불러오려면 게임 안 **설정 → 내 세이브 목록**에서 선택하세요.
- 런처는 설치/업데이트가 필요한 동안 **[게임 시작] 버튼을 잠그고**, 설치가 끝나면 자동으로 활성화합니다.
- 설치·업데이트 후 게임을 자동 실행하지 않습니다. **[게임 시작]** 을 눌러 시작하세요.
- 불러오기 중 클라우드 저장 확인이나 세이브 복원이 실패해도 콘솔 예외로 남지 않고 안내 메시지로 처리합니다.

### 요정 직업과 요정의 지팡이 (v1.17.0)

메인코어 근처에서 **E → 전직**으로 새 직업 **요정(🧚)** 을 고를 수 있습니다.

- 요정은 **요정의 지팡이** 계열 전용입니다. 다른 직업의 무기는 잠기고, 다른 직업은 요정의 지팡이를 쓸 수 없습니다.
- 전직하면 **T1 「요정의 지팡이」를 자동 지급**합니다. 이미 가지고 있으면 중복 지급하지 않습니다.
- T2~T7은 제작대(C)에서 해당 티어 제작대를 지은 뒤 만들 수 있습니다.
  T1 요정의 지팡이 → T2 꽃망울 → T3 이슬빛 → T4 달빛 → T5 여왕의 → T6 세계수의 → **T7 요정 여왕의 홀**.
- 요정의 지팡이는 일반 지팡이처럼 마법을 습득해 쓰는 방식이 아니라, **무기 티어 피해가 그대로 들어가는 추적 꽃가루**를 발사합니다.
  꽃가루가 가장 가까운 적을 따라가고, 명중하면 꽃잎 임팩트가 터집니다.
- 요정 패시브: 마나 회복 ×1.3 · 이동 속도 ×1.08 · 무기 피해 ×1.08 (전직 단계에 따라 증가).

### 서버 포트 바꾸기 (v1.16.0)

게임에서 **관리자로 로그인 → 설정 → 서버 · 포트**에서 `1024~65535` 사이의 새 포트를 입력하고
**[포트 변경 · 재시작]** 을 누르면 됩니다.

- 새 포트에 서버가 먼저 뜬 것을 확인한 뒤 이전 서버를 내리고, 브라우저가 새 주소로 이동합니다.
- 진행 중인 멀티플레이 방은 종료됩니다. 다시 방을 만들어야 합니다.
- 주소가 바뀌면 브라우저 저장소도 달라지므로 **로그인·닉네임은 새 주소에서 다시 설정**해야 할 수 있습니다.
- 포트는 `.env` 의 `PORT` 한 줄에 저장되므로 **다음 실행부터도 그 포트**로 뜹니다.
- 바꾼 포트를 다른 기기에서도 열려면 `run.cmd firewall` 을 관리자 권한으로 한 번 실행하세요
  (현재 포트를 자동으로 읽어 방화벽 규칙을 추가합니다).
- `게임실행.vbs` · `게임앱.vbs` · `run.cmd` · 개발 런처가 모두 `.env` 의 포트를 읽습니다.

## 👥 친구

**`U`** 키로 친구창을 엽니다.

1. 친구창 위쪽에 **내 친구 코드**가 있습니다 (예: `ABCD-EFGH`) — [코드 복사] 로 복사해 친구에게 알려 주세요.
2. **[＋ 친구 추가]** → 열리는 입력창에 **친구 코드**를 넣고 [추가] 를 누릅니다.
3. 친구가 같은 서버(같은 PC·LAN)에 접속해 있으면 **접속 중** 으로 바뀌고 방 코드가 표시됩니다.
4. **[들어가기]** 를 누르면 친구의 서버(`http://주소/?room=방코드`)로 이동해 그 방에 참가합니다.
   - 주소를 모르면 안내 창에서 친구가 알려 준 `IP:포트`(예: `192.168.0.12:3001`)를 한 번만 입력하면 저장됩니다.
5. 친구를 지우려면 카드의 **[삭제]** 를 누릅니다.

> 친구 코드는 이 PC 에 저장됩니다. 서버는 접속 중인 플레이어의 코드·방 코드만 메모리에 두고 30분 동안 갱신이 없으면 오프라인으로 봅니다.

## ⚙️ 설정

`.env` 파일을 만들고 값을 채우세요 (`.env.example` 참고):

```ini
PORT=3001
NODE_ENV=production
ADMIN_USERNAME=admin
ADMIN_PASSWORD=여기에_강력한_비밀번호
ADMIN_NICKNAME=관리자
AUTH_SECRET=여기에_무작위_문자열
```

> ⚠️ `AUTH_SECRET` 은 **반드시** 바꾸세요. 이 값으로 로그인 토큰을 서명합니다.
> 무작위 값 만들기: `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`

`PORT` 는 게임 안 **설정 → 서버 · 포트**에서도 바꿀 수 있습니다. 이때 `.env` 의 `PORT` 줄만 바뀌고
다른 값(관리자 비밀번호·JWT)은 그대로 유지됩니다.

### 관리자 계정

서버를 켜면 `.env` 의 값으로 **자동 생성/갱신**됩니다.
관리자만 `` ` `` 콘솔에서 명령어를 쓸 수 있습니다 (`/돈`, `/무기`, `/웨이브` 등).

- `.env` 에 `ADMIN_PASSWORD` 가 있으면 그 값이 항상 적용됩니다(서버 재시작 포함).
- 없으면 `server/data/admin-password.txt` 에 **한 번만 생성해 보관**하고, 다음 시작부터는 그 값을 씁니다.
  예전처럼 매 시작마다 무작위로 바뀌어 로그인할 수 없는 일은 없습니다.
- 비밀번호를 잊었다면 위 파일을 확인하거나 `.env` 의 `ADMIN_PASSWORD` 를 바꾼 뒤 서버를 다시 시작하세요.
- `/api/net` 의 공유 주소는 **실제 `PORT` 환경변수**를 사용합니다. 테스트(`node tools/e2e-net.mjs`)도
  `E2E_BASE` 의 포트를 읽으므로 3001 이 아닌 포트에서도 그대로 검증됩니다.

## 📁 구조

```
client/            게임 클라이언트 (Three.js)
  src/
    main.js        게임 루프 · 상태
    ui/            메뉴 · 패널 · HUD · 콘솔
    systems/       전투 · 웨이브 · 제작 · 마법 · 업적
    world/         지형 · 건물 · 자원 · 하늘
server/            게임 서버 (Express + Socket.io)
  api/             REST (auth · save · leaderboard · admin)
  game/            방 관리 · 프로토콜
tools/             테스트 · 빌드 도구
installer/         설치 프로그램 (PowerShell + C#)
```
