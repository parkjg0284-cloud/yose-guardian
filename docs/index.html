Features

요새에서 벌어지는 일들

혼자서도, 친구와 함께서도 — 매번 다른 세계에서 요새를 지켜냅니다.

👹

몬스터 11종

뿔 · 턱 · 이빨 · 발톱 · 망토 · 날개까지 — 종류마다 다른 괴물 실루엣과 움직임.

🛡️

요새 방어

웨이브를 막으며 포탑 20종을 세우고, 제작대에서 만든 포탈로 지형을 넘나들며 보스 웨이브를 버텨냅니다. 건물은 50개, 시설은 40개까지. 티어마다 포탑 피해가 47%씩 오르고, 서버 포트도 게임 안에서 바꿀 수 있습니다.

🧙

전직 · 마법 연성

8개 계열로 전직하고, 전직할 때 그 직업의 1티어 무기를 받습니다. 새 요정 직업은 전직 시 요정의 지팡이를 받고, T2~T7은 제작대에서 만듭니다.

👥

친구와 협동

초대코드로 최대 4인 협동. 코드를 만든 직후나 방장이 잠깐 끊겨도 코드가 유지되고, 연결이 끊겨도 45초 안에 돌아오면 그 자리에서 이어서 합니다.

🌱

절차 생성 세계

시드 기반 지형과 난이도 5단계 — 시드 갤러리에서 공유할 수 있습니다. 나무·광물은 6초 만에 다시 자랍니다.

🔨

철거 · 세이브

Z 로 조준한 포탑·시설을 철거하면 투자 재료의 25% 를 돌려받고, 저장한 게임은 설정의 세이브 목록에서 이어서 합니다.

Patch Notes

패치노트

런처의 [패치노트] 버튼에서도 같은 내용을 볼 수 있습니다.

🔥

v1.19.0 · 지옥 난이도 · 디아블로 · 캐릭터 리뉴얼

난이도별 몬스터가 더 강해지고, 지옥 100 웨이브 끝에 디아블로가 기다립니다.

  • 난이도별 몬스터 체력·공격력 동시 상승 (평온 → 표준 → 도전 → 악몽 → 지옥)
  • 지옥 = 100 웨이브 고정 · 100 웨이브를 막으면 승리
  • 디아블로 — HP 1,000,000,000 · 공격력 1,700,000 · 지옥불 패턴
  • 멀티 캐릭터 고품질 3D 모델 · 신규 외형 천상기사
  • 런처 [업데이트 내역] → [패치노트]
🧹

v1.18.0 · 메인화면 정리 · 시작 버튼 잠금

메인화면의 불러오기 버튼을 정리하고, 런처 시작 버튼을 안전하게 바꿨습니다.

  • 싱글·멀티 카드의 [불러오기] 버튼 제거 — 세이브는 설정의 세이브 목록에서
  • 설치·업데이트 중 [게임 시작] 잠금 → 완료 후 자동 활성화
  • 설치 후 자동 실행 제거 · 불러오기 오류 처리 보강
  • 오프라인 런처의 설치 버전 판정 수정
🧚

v1.17.0 · 요정 직업과 요정의 지팡이

새 직업 요정과 요정의 지팡이 7티어를 추가했습니다.

  • 요정의 지팡이 T1~T7 — T1 요정의 지팡이 → T7 요정 여왕의 홀
  • 요정으로 전직하면 T1 요정의 지팡이 자동 지급
  • T1~T7 제작대 레시피 · 전직 잠금 · 대표 무기 반영
  • 꽃가루가 적을 추적하는 전용 공격과 꽃잎 뷰모델
🔌

v1.16.0 · 서버 포트 변경

관리자 설정에서 서버 포트를 바꾸면 새 포트로 자동 재시작합니다.

  • 설정 → 서버 · 포트 · 1024~65535
  • 실패 시 .env 원복 · 기존 서버 유지
  • 실행 파일 · 설치 프로그램 · 방화벽이 .env 의 PORT 를 따름
🏹

v1.15.0 · 티어별 포탑 피해

몬스터 체력을 기준으로 포탑 피해를 티어별로 다시 맞췄습니다.

  • 건물 50 · 시설 40 제한
  • 맨땅 채굴 · T1 직업 무기 지급
  • 나무·광물 6초 리스폰
